# 메인 화면 첫 장면 영상

이 폴더에 영상 파일을 올리면, 메인 화면(daehantax.com) 맨 위에서 **차례로 돌아가며(롤링)** 재생됩니다.
따로 코드를 고칠 필요가 없습니다. 올리고 1~2분 뒤 사이트에 반영됩니다.

## 올리는 법 (휴대폰·PC 모두 가능)
1. GitHub 에서 `daehantax/daehantax-com` 저장소 → `assets/video` 폴더로 들어갑니다.
2. **Add file → Upload files** 로 영상을 끌어다 놓고 **Commit changes**.
3. 끝. (자동 작업이 영상 목록을 새로 만들어 줍니다)

## 영상 만들 때 권장
- 길이 **8~15초**, 가로 영상, **소리 없음**(메인 화면에서는 소리가 나지 않습니다)
- 파일 형식 **mp4**, 크기 **10MB 이하** (클수록 휴대폰에서 늦게 뜹니다. GitHub 웹 업로드 한도는 25MB)
- 사무실 주변 거리, 사무실 안, 회의 장면처럼 **천천히 움직이는 장면**이 잘 어울립니다.
- 순서를 정하려면 파일 이름 앞에 `01_`, `02_` 를 붙이세요. (예: `01_야탑역_아침.mp4`)
- 같은 이름의 `.jpg` 를 함께 올리면 영상이 뜨기 전 잠깐 보이는 첫 화면으로 씁니다. (예: `01_야탑역_아침.jpg`)

## 빼고 싶을 때
이 폴더에서 그 영상 파일을 지우면 됩니다.
